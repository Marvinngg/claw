## SOP: evaluateMarginalContribution（边际贡献评估）

当用户考虑在已有持仓的情况下新增标的时执行。

**步骤**：
1. 询问或推断当前持仓（各标的 + 大致仓位占比）
2. 计算新标的与现有持仓的相关性：
   - 同行业/同板块：高度相关 → 风险集中警告
   - 不同行业但政策同向（如"新能源"+"储能"）：隐性相关
   - 防御性资产 vs 进攻性资产：对冲效果评估
3. 评估加入后的组合影响：
   - 行业集中度变化
   - 单标的仓位是否超过30%（超过需警告）
   - 总体风险是上升/下降/不变
4. 输出格式：
```
[当前组合] 行业分布：XX%制造/XX%消费...
[新标的影响] 与持仓相关性：高/中/低
[集中度] 加入后 TOP3 标的占比：XX%
[建议仓位] 基于风险预算的合理仓位上限
[结论] 是否适合加入，理由
```

## SOP: conduct_scenario_analysis（情景分析）

对单标的或组合执行牛/基/熊三路径分析。

**步骤**：
1. 定义时间框架（3个月/6个月/1年）
2. 构建三个情景：
   - **牛市情景**（概率X%）：催化剂是什么？目标价位？
   - **基准情景**（概率Y%）：最可能发生的路径
   - **熊市情景**（概率Z%）：最大回撤在哪里？
   - 约束：X + Y + Z = 100%
3. 计算期望回报：
   - 期望收益 = 牛市涨幅×X% + 基准收益×Y% + 熊市跌幅×Z%
   - 若期望收益 < 无风险利率（约2.5%），不值得承担风险
4. A股情景分析特殊考量：
   - 政策突然转向的尾部风险（分配额外5-10%概率）
   - 流动性枯竭风险（小盘股需要单独处理）
5. 输出格式：
```
[牛市 XX%] 触发条件 → 目标区间
[基准 YY%] 预期走势 → 目标区间
[熊市 ZZ%] 风险情境 → 下行区间
[期望回报] XX%（年化）
[风险回报比] 上行/下行 = X倍
[结论] 值得/不值得/需要等待
```

## SOP: analyzePortfolioCorrelation（组合相关性分析）

用户提供多个持仓时，分析整体组合健康度。

**步骤**：
1. 列出所有持仓标的及大致仓位
2. 按维度分组：
   - 行业分布（制造/消费/科技/金融/医药...）
   - 市值分布（大盘/中盘/小盘）
   - 政策敏感度（强政策驱动/弱政策依赖）
3. 识别集中风险：
   - 单行业>40%：需要分散
   - 所有标的都是政策驱动：系统性风险高
   - 所有标的都是小盘：流动性风险高
4. 分散建议（基于发现的集中点）

**快捷判断矩阵**：
| 情况 | 诊断 | 建议 |
|------|------|------|
| 3只同行业标的 | 行业赌注，不是组合 | 保留最强，减少其余 |
| 全是题材股 | 情绪驱动，基本面空虚 | 加入1只防御性标的 |
| 全是大盘蓝筹 | 安全但缺弹性 | 视风险承受度保持或微调 |

## SOP: conduct_initial_risk_triage（风险分诊）

SKILL.md STEP 1 的详细执行步骤。

**检查清单**（按顺序）：
1. **退市风险**：WebSearch "{股票名} 退市风险 2024-2025"
   - ST/ST*/退市整理板 = 🔴
2. **财务造假信号**：大股东频繁减持+业绩靓丽+审计意见保留 = 🔴
3. **监管调查**：证监会立案调查 = 🔴
4. **质押风险**：控股股东质押率 > 80% = 🟠
5. **连续亏损**：扣非净利润连续2年为负 = 🟠
6. **停牌原因**：不明原因停牌 > 5天 = 🟠 需核查

**触发 🔴 后必须输出**：
```
⚠️ 最高级别警报：[具体风险描述]

当前发现的风险足以构成一票否决。强烈建议在此风险解除前，
暂停对该标的的任何仓位操作。

具体风险：[详述]
建议行动：[查明/等待/回避]
```
